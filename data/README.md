# RutaIbagué pilot dataset (GTFS)

This folder holds the transit network used by the RutaIbagué agent, in the
[General Transit Feed Specification (GTFS)](https://gtfs.org/) format.

**Important: this is SAMPLE data.** No open dataset of Ibagué's bus routes was
found. The 28 stops are placed at approximate coordinates of well-known places
in Ibagué, and the 8 routes are illustrative, not the official routes of the
bus companies. Frequencies and speeds are assumptions. To use real data, replace
the files in `gtfs/` with a field-verified feed; the app and the agent read it
without code changes.

| File | Content |
|---|---|
| `gtfs/agency.txt` | Publisher of the pilot feed |
| `gtfs/stops.txt` | 28 stops: id, name, latitude, longitude |
| `gtfs/routes.txt` | 8 routes: id, name, color |
| `gtfs/trips.txt` | 16 trip patterns (one per route and direction) |
| `gtfs/stop_times.txt` | Stop order of each pattern and off-peak running times |
| `gtfs/frequencies.txt` | Headways: daytime (05:00–21:00) and night (21:00–24:00, double headway) |
| `gtfs/calendar.txt` | Daily service |
| `gtfs/feed_info.txt` | Feed version (`pilot-1.0`) |

The feed is generated by `tools/build_gtfs.js` from `tools/pilot_network.js`.
After editing the network, run `npm run build:data`.

Agent parameters that are not part of GTFS (in `js/agent.js`):
bus speed 13 km/h (peak: 6:00–8:30, 11:30–14:00, 17:00–19:30), 19 km/h
(off-peak), 22 km/h (night, from 21:00); walking 4.5 km/h; route detour factor
1.35; walking detour factor 1.25; dwell time 0.4 min per stop; maximum access
walk 800 m; maximum transfer walk 350 m.
